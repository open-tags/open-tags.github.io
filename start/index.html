TWR quick start

Two tags. One live distance trace.

Flash both roles, connect over USB, calibrate at a known distance, and export your first measurement run.

Open firmware console Read the steps

Before you start

Hardware

Two opentag one units, two USB-C data cables, and a rigid way to hold the tags at a measured distance.

Browser

Chrome or Edge on desktop. WebUSB and Web Serial must be available; Safari and Firefox do not currently support this workflow.

Ground truth

Use a tape or laser distance meter. Measure between consistent physical reference points and keep the antennas facing the same way.

Quick start 1. Flash roles 2. Connect 3. Calibrate 4. Measure 5. Export Troubleshooting
01

Flash the two roles

  1. Open the firmware console in Chrome or Edge.
  2. For Tag A, unplug USB, hold BOOT0, and plug USB back in while continuing to hold the button.
  3. Select Flash Initiator, choose the STM32 DFU device, and wait for completion.
  4. Unplug Tag A, release BOOT0, and reconnect it normally.
  5. Repeat the sequence for Tag B using Flash Responder.

Expected result: each flash panel says it is done and asks you to replug normally.

02

Connect both serial ports

  1. Select Connect serial under Tag A and choose its USB serial device.
  2. Repeat under Tag B, choosing the other device.
  3. Confirm the mode indicators show I for Tag A and R for Tag B.

Expected result: the Live Distance chart begins receiving D sequence millimeters samples from the responder.

03

Calibrate the pair

  1. Place the tags with clear line of sight at a carefully measured distance. Keep them still and away from large metal surfaces.
  2. Enter that distance in millimeters under Pair Calibration.
  3. Leave Tag B selected as the responder and collect at least 100 samples.
  4. Select Start calibration and wait for the new antenna-delay offset.

The console writes the new offset to the responder and remembers it locally for later browser flashes.

04

Run a static test

  1. Move the tags to a new measured separation without changing antenna orientation.
  2. Enter the true distance and test duration under Static Test.
  3. Select Start Test. Do not move the tags during the run.
  4. Review mean error, standard deviation, sample count, and the live trace.
05

Export the evidence

Select Download Test CSV. The file includes test metadata, summary statistics, timestamps, every measured distance, ground truth, and signed error. Keep the unedited CSV with notes about distance, environment, antenna orientation, and obstructions.

Troubleshooting

No DFU device appears
Use a data-capable cable. Unplug, hold BOOT0 before reconnecting, and try the flash action again.
No serial device appears
Replug without holding BOOT0. Close other serial monitors and confirm the operating system sees the USB device.
Connected but no samples
Press INFO and confirm Tag A reports mode I and Tag B reports mode R. Keep both tags powered and within clear line of sight.
Large fixed error
Repeat pair calibration with an accurately measured distance and unchanged antenna orientation.
