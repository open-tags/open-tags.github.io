opentag one documentation

Measure distance between two tags, or set up anchors for indoor location.

Start here

Distance quickstartTwo tags. Flash the roles, connect USB, and get your first measurement. Location quickstartThree anchors for 2D or four for 3D, plus one mobile tag. Python toolsDownload the scripts to read distance and save CSVs outside the browser. ROS 2 integrationPackage requirements, setup, topics, and connection checks.

Choose the right interface

TaskUseKnow before starting
DistanceBrowser or USB serialThe responder reports the measurement; the initiator also needs power.
LocationBrowser or USB serialSurvey the anchors before configuring firmware.
CalibrationBrowser; Python for distanceRuntime calibration is lost on reset unless restored or included in the flashed image.
ROS 2USB serialRequires the driver source package; no public package download is linked yet.
Range over CANNot releasedCAN hardware and standalone test programs are separate from the USB ranging firmware.

Use it without the browser

Start with the Python tools download and installation. Only one application can own a tag's serial port at a time: disconnect it in the console before opening Python or ROS 2.
